# 功能说明与场景

**Super Leader Bot 让你通过微信管理电脑上的 AI 会话。** 你交代任务，机器人查询状态、安排步骤、传递结果。

| 分组 | 功能 | 你交代什么 | 机器人负责什么 |
| --- | --- | --- | --- |
| 基础功能 | **问答与文字整理** | 问题或文字，以及输出要求 | 解答问题，改写或整理文字 |
| 基础功能 | **联网搜索与网页阅读** | 问题或网页链接 | 查找资料，整理结论和来源 |
| 基础功能 | **聊天记忆** | 要保存、修改或删除的偏好和事实 | 更新记忆，在后续聊天中使用 |
| 基础功能 | **会话查询** | 机器、项目或会话名称 | 列出会话，显示状态 |
| 基础功能 | **进展查询** | 会话名称和要了解的问题 | 读取历史，整理进展和待办 |
| 基础功能 | **图片回传** | 会话名称和图片描述 | 找到会话中的图片，发送到微信 |
| 基础功能 | **CLI 终端操作** | 已接入的终端和输入内容 | 读取终端记录，发送指定输入 |
| 基础功能 | **Web 控制台** | 打开控制台的要求 | 提供登录链接，展示会话和任务 |
| 任务执行 | **任务派发** | 会话名称和任务内容 | 发送任务，报告执行结果 |
| 任务执行 | **技能组合** | 技能名称和使用顺序 | 查找技能，交给会话按顺序使用 |
| 任务执行 | **连续补充：steer** | 处理中追加的信息或要求 | 将补充加入当前轮，继续处理 |
| 任务执行 | **任务排队** | 会话名称和待办任务 | 保存任务，等会话可用后发送 |
| 任务执行 | **进度与成果** | 要跟进的任务 | 报告进展，交付完整结果 |
| 多会话协作 | **Plan：固定计划** | 任务步骤和执行顺序 | 按步骤执行，把结果交给下一步 |
| 多会话协作 | **Goal：持续目标** | 目标、完成条件、范围、次数和时限 | 根据每轮结果安排下一步 |
| 多会话协作 | **计划预览与取消** | 预览要求或取消指令 | 展示安排，或停止后续步骤 |
| 定时与后台 | **提醒与定时任务** | 时间、执行频率和任务内容 | 按时提醒或执行，报告结果 |
| 定时与后台 | **跨机器结果汇总** | 定时任务名称和汇总时间 | 收集各机器的任务结果，按时汇总 |
| 定时与后台 | **独立后台任务** | 任务内容和所需资料 | 创建后台会话，完成任务并交付结果 |
| 定时与后台 | **后台追问与延期** | 补充问题和保留时间 | 继续原后台任务，延长会话保留期 |

**基础功能**

**用问答与文字整理，你在微信说：**

> 帮我把下面这段技术讨论整理成结论、分歧和下一步。

机器人阅读文字，按你的要求整理要点。你也可以让它解释概念、比较方案或修改表达。

**用联网搜索与网页阅读，你在微信说：**

> 查一下这两个框架最近的版本变化。再读我发的公开文章，解释这些变化对选型的影响，并附来源。

**搜索资料 → 读取网页 → 整理结论和来源。**

机器人把多个来源的资料整理成答案，帮助你比较方案。

**用聊天记忆，你在微信说：**

> 记住，我希望你先给结论，再给证据。时间默认按北京时间说。

机器人保存这个偏好，并在后续聊天中使用。你还可以要求查看、修改或删除已保存的记忆。

**用会话查询，你在微信说：**

> 看看 节点 A 和 节点 B 上有哪些项目会话，哪些正在执行任务。

机器人列出两台机器的会话，并显示状态。你在微信里就能查看各项目的工作情况。

**用进展查询，你在微信说：**

> 看一下“支付重构”会话最近完成了什么，还有哪些待办。

**找到会话 → 读取历史 → 整理进展和待办。**

机器人从聊天记录中提取要点，帮你快速了解任务进展。

**用图片回传，你在微信说：**

> 把“页面设计”会话刚生成的页面预览图发给我。

机器人找到该会话中的图片，并发到微信。你可以直接在手机上查看设计结果。

**用 CLI 终端操作，你在微信说：**

> 查看这个已接入终端的最近输出，再向它发送：只读检查当前测试结果。

机器人读取终端记录，并写入你指定的内容。你可以在微信里向终端交代任务。

**用 Web 控制台，你在微信说：**

> 给我控制台链接，我想看看哪些任务在排队、哪些已经完成。

机器人提供登录链接。打开后，你可以查会话、读历史、发任务、取消排队任务，也可以查看计划、目标和定时任务。

**任务执行**

**用任务派发，你在微信说：**

> 让“代码审查”会话检查这个提交，只读检查，完成后把结果给我。

机器人将任务发到指定会话，并报告执行结果。你也可以在电脑上打开原会话查看过程。

**用技能组合，你在微信说：**

> 让开发会话检查已修复的提交。先用代码审查技能检查修改，再用验证技能核对修复结果。

**查找技能 → 核对顺序 → 将技能和任务交给会话。**

机器人负责查找技能并传递使用要求，省去你查路径和逐项交代的操作。

**用连续补充，你在微信说：**

> 帮我比较这两个技术方案。

处理过程中，再发：

> 补充一下，优先考虑维护成本，团队只有两个人。

机器人把补充加入正在处理的这一轮，并结合两条消息给出答案。你可以边想边补充要求。

给电脑上的开发会话补充要求时，你可以说：

> 给开发会话正在处理的这一轮补充：工作范围是修复和验证，完成验证后停下。

机器人核对正在运行的轮次，再把补充发给该会话。

**用任务排队，你在微信说：**

> 开发会话忙完后，再让它检查错误日志。

**保存任务 → 等会话可用 → 按顺序发送。**

机器人负责等待和发送。你可以提前安排下一项工作。

**用进度与成果，你在微信说：**

> 让开发会话排查这个问题。有进展时告诉我，完成后把完整结论给我。

机器人报告已确认的进展，并在任务完成后交付结果。会话任务和后台任务的较长成果使用摘要和完整文件交付。你可以先看结论，再读详细内容。

**多会话协作**

**用 Plan，你在微信说：**

> 让开发会话修复重复回复的问题。完成后，把修改说明交给测试会话做回归，再让审查会话检查。最后把结果发我。

**开发修复 → 测试回归 → 审查检查 → 汇总结果。**

机器人按确定的步骤推进。前一步完成后，它把结果交给下一步。你一次交代，就能安排完整流程。

**用 Goal，你在微信说：**

> 持续推进重复回复问题，直到回归通过且审查通过。使用开发、测试、审查这三个会话。最多派发 6 次，持续 30 分钟。工作范围是修复和验证。

它可能这样推进：

**开发修改 → 测试发现一个边界问题 → 开发补充修复 → 再次验证 → 核对完成条件。**

机器人根据每轮结果安排下一步。你设定目标、范围和预算，机器人负责协调后续工作。

**用计划预览与取消，你在微信说：**

> 先给我一个开发、测试、审查的执行安排，等我确认后执行。

机器人展示步骤和分工。你确认后，它开始执行。

要取消后续步骤时，说“取消计划”或“取消目标”。机器人停止后续推进，让你调整工作安排。

**定时与后台**

**用提醒与定时任务，你在微信说：**

> 明天上午九点提醒我检查部署。

安排重复任务时，说：

> 每天上午九点让运维会话检查服务，有变化时通知我。

**保存时间和任务 → 到点触发 → 记录结果 → 按要求通知。**

你交代一次，机器人按时间执行。你还可以查询、暂停、恢复或取消定时任务。

**用跨机器结果汇总，你在微信说：**

> 每天上午十点检查 节点 A 和 节点 B 上今天的日报定时任务。等它们完成后汇总给我，最晚十一点交付，并列出缺项。

**找到定时任务 → 等待本轮结果 → 收集报告 → 按时汇总。**

机器人集中整理各机器的结果。你在微信里查看一份汇总即可。

**用独立后台任务，你在微信说：**

> 独立开一个后台任务，查询这三个公开工具的功能和价格。完成后，把对比结果给我。

机器人创建独立后台会话，查资料并整理结果。你交代任务后，可以继续处理其他事情。

**用后台追问与延期，你在微信说：**

> 继续刚才的工具对比，补充每项价格的来源。把这个后台会话保留到从现在起 24 小时后。

**恢复原上下文 → 补充分析 → 交付结果。**

机器人沿用已有资料继续工作，并按要求延长会话保留期。你可以围绕同一份结果持续追问。

**你负责确定任务和目标，机器人负责查询、安排、等待和交付。**
