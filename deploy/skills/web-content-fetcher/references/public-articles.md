# 公开文章与验证页

## 微信公众号

读取用户给出的 `mp.weixin.qq.com` 原链接，并保留查询参数。优先提取 `#js_content` 或 `.rich_media_content`；这些容器有时标记为隐藏，但 HTTP 已包含正文。Markdown 图片会使用 `data-src` 懒加载地址。

核对文章标题、作者、发布时间和正文覆盖范围。标题或正文显示“环境异常”“访问过于频繁”“请完成验证”“内容已被发布者删除”“该内容已被投诉”等提示时，将其作为无法读取的证据。不要根据文章 URL、搜索摘要或公众号名称猜测正文。

## 火山引擎等文档站

HTTP 200 可能只返回 “Please wait...” 或 “Just a moment...” 挑战页，也可能只有 JavaScript 导航壳。真正读到正文后，保留代码、参数表、版本和更新时间；没有正文时报告挑战或渲染限制。

## X 等动态内容站

公开 HTTP 可能返回登录页或仅含脚本的页面。根据实际取得内容判断；未取得指定推文、长文或列表时，报告受限，不能把推荐内容当作目标正文。
