# 按需读取远程任务结果

新增 `/task <任务ID> [页码]`，默认第一页，每页最多 2000 个原始字符，展示节点、存储状态和页码，并给出下一页指令。`/tasks` 明确为摘要，并提示详情入口。复用现有 SQLite 结果，无新增执行或自动发送流程。

通过 `NodeRegistry.get_task` 主键查询；与列表查询一样先结算过期运行租约，显示 uncertain 而非过时的 running。权限仍使用已有聊天白名单，未授权请求在查询前拒绝。

## 验证

新增 14 个用例：空结果、边界长度、跨页重建、错误页码/参数、未知任务、授权拦截、帮助入口、过期状态、重新创建实例后读取尾页。

实测 `.venv/bin/python -m pytest -q`：224 passed in 2.15s；`.venv/bin/python -m compileall -q src`、`git diff --check` 通过。

## 证据边界

- 使用临时 SQLite 和实际应用路由，无真实微信发送、Codex 执行或跨机调用；重启用重新创建应用实例模拟。
- 测试中原始分页内容拼接等于原结果，常规中文/emoji 页面通过传输转换后没有超限提示。未证明任意超长任务 ID/节点名、复杂 Markdown 或极端 Unicode 在客户端显示完整。
- 分页按 Python 字符计数，不是字节或字素；可能从代码块、链接或组合 emoji 中间切开。每页仍经过既有 Markdown 降级，`CommandResult.data.result` 保留原始片段。
- 读取的是每次请求时的结果，没有多页快照锁定；运行中到终态或管理端覆写结果可能改变页数，建议完成后读取。没有性能、时延推算，本轮无外部接口故障。
- 仍沿用已有全局授权聊天模型，尚无任务归属 ACL；不是多租户安全实现。
