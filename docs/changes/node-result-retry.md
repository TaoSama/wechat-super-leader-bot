# 节点结果上报有界重试

## 行为

节点执行结束后的 `/nodes/task-status` 上报，遇到 URLError、OSError（含超时、连接断开）或 HTTP 429/5xx 时，最多发送 3 次，重试等待依次为 1、2 秒。只重传相同终态与结果，不再次执行任务、不重新领取任务或重新注册节点。其他 HTTP 错误、无效响应和 `updated != true` 立即失败。重试耗尽保留原异常，并记录异常类型和次数，不记录异常正文或凭据。

复用服务端既有终态幂等规则：同一节点、同一任务、相同终态与结果可以重复确认。没有引入新的状态转换或自动重排队。

## 验证

- `tests/test_node_result_retry.py`：模拟临时错误、永久拒绝、重试耗尽、日志脱敏和执行次数。
- `tests/test_local_workflow.py`：真实本机 HTTP 写入成功后，在客户端包装层模拟确认丢失，再次请求确认成功；成功和失败结果均覆盖，执行器只调用一次。
- 验证命令：`.venv/bin/python -m pytest -q`、`.venv/bin/python -m compileall -q src`、`git diff --check`。
- 本轮实测：179 passed in 2.05s，编译及差异检查通过。新增 16 个错误分类用例和 8 个确认丢失 HTTP 用例。

## 证据边界与剩余工作

- HTTP 回环服务是真实执行；微信、Codex 执行器、跨机网络和网络故障本身均未进行真实联调。没有发送外部消息或读取真实凭据。
- 等待时间通过替换 sleep 检查参数，不是墙钟耗时实测；请求超时并非整个工作流的严格耗时上限。
- 本轮没有真实外部接口故障；故障证据来自测试注入，并以本机 HTTP 幂等确认交叉验证。
- 独立测试子代理未返回进度且未生成文件，主 Agent 中断子任务后接手完成；没有足够证据归因为接口错误，独立评审未完成。
- 结果仍只保存在内存：进程退出或重试耗尽后不能自动恢复；持久化 outbox、身份/attempt fencing、轮询恢复仍待实现。不要把有界重试视为可靠投递保证。
- 重试当前不读取 Retry-After；固定短重试可能耗尽，耗尽后明确失败而非无限重试。
- 回退本轮改动时只移除 `_report_task_result` 调用与辅助方法、两个重试常量及本轮测试增量，保留之前未提交的心跳和派发修复。
