# 显式聊天默认节点路由

新增 `/bind <节点>` 和 `/unbind`。授权聊天绑定一个已注册且在线的节点后，普通文本才会创建任务并派发；绑定按 chat_id 存在 SQLite，重启保留，其他聊天不继承。节点离线时不执行，文本仍保存为记忆并明确 accepted=false。

未绑定的普通文本继续只记录记忆，不会凭关键词猜目标，也不再声称“正在分析”。`/help` 已说明绑定流程。

验证：`.venv/bin/python -m pytest -q` 实测 122 passed；新增每聊天隔离、绑定、解绑和派发测试，compileall、git diff --check 通过。

证据边界：绑定后任务仍受节点租约、结果回传和外部副作用窗口约束；没有自然语言模型规划、任务所有权 ACL 或真实微信/远程节点数据。本轮未发送外部消息。
