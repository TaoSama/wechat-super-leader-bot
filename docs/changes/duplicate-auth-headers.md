# 重复鉴权头拒绝

GET/POST 在读请求体和路由处理前检查 Authorization、X-Node-Token；重复字段（大小写不敏感）返回 JSON 401，并关闭连接。同值重复也拒绝，不选择第一个或最后一个值。

验证：`.venv/bin/python -m pytest -q` 实测 155 passed；compileall、git diff --check 通过。新增 9 个回环 HTTP 用例覆盖消息、节点心跳、领取接口及有效值的排列；声明但未发送请求体，验证提前拒绝。测试服务均关闭，无常驻进程。

证据边界：使用占位 token，未读取真实凭据或发送外部消息。未测试上游代理合并、删除重复头后的行为，没有进行时序基准或全面安全审计。无外部接口异常或重试，当前无新增开发阻塞。
