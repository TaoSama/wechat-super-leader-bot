# 会话文件消失时继续发现

扫描期间 stat 或元信息 open 返回 FileNotFoundError 时跳过该文件，不消耗列表限额；按 ID 查询时目标在发现后消失则继续查找。stat 元信息只获取一次并复用于排序与 updated，非普通文件不加入候选。元信息读取不再把所有 OSError 当作文件名回退，权限和其它 IO 错误明确传播；无效 JSON 仍保留原文件名回退行为。

按开发技能做本地文件逻辑最小修复，未更改 Codex 协议、CLI 或日志文件。

## 验证

新增 6 个用例：同后缀目录跳过、stat/open 消失分别容错且补足 limit、两个阶段权限错误传播、查询阶段消失返回 None。

实测 `.venv/bin/python -m pytest -q`：273 passed in 2.34s；`.venv/bin/python -m compileall -q src`、`git diff --check` 通过。

## 证据边界

使用临时文件及路径方法故障注入，没有读取用户真实会话或实际删除日志。元信息扫描和按 ID 查询分别验证，不是对操作系统并发文件删除的压力测试；没有内存/延迟测量或性能推算。本轮无外部接口调用或异常。

仍不是事务快照：文件可在 stat 后替换为目录、符号链接或其它内容；此类非消失错误仍传播，未实现文件描述符级竞态防护。已发现条目也可能在返回后过时。递归枚举自身的权限行为依赖 pathlib 版本，不能据此宣称所有权限错误都可见。权限错误可能让整轮节点上报停止，这是明确失败而非伪造成功。

回退仅恢复旧扫描、元信息异常捕获和 get 打开方式，保留其它已有会话历史改动。
