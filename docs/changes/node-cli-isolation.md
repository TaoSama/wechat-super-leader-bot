# 远程节点启动不初始化控制面

CLI --node-agent 校验参数后直接构造 NodeAgent 并使用其默认执行器，不再先初始化 SuperLeader 的节点/记忆数据库、技能路由及桌面客户端，也不再重复定义独立会话执行函数。节点运行返回后明确结束该分支；异常原样传播。

按开发技能最小改动原则复用已有默认执行器。--data-dir 在纯节点模式下不创建控制面目录；这不意味着已有节点结果持久化，本轮没有添加本地 outbox。

## 验证与证据边界

新增 3 个用例覆盖正常返回、异常和中断：禁止 SuperLeader 初始化，使用真实 NodeAgent 构造检查 URL/身份参数、默认执行器绑定及文本输出，最后断言控制面目录不存在。run 与会话执行为替身，不联网、不调用真实模型或读凭据。

实测 `.venv/bin/python -m pytest -q`：348 passed in 2.63s；compileall、git diff --check 通过。参数/执行路径与文件系统结果交叉核对；未量化启动时延或资源占用，无性能推算或外部接口异常。

节点真实注册/恢复及可靠结果补报仍未完成端到端验证。回退只恢复 CLI 原分支和重复执行器，不改磁盘数据。本轮没有删除任何已有目录或数据库。
