# 节点领取 URL 编码

客户端将整个节点名编码为单个 URL 路径段；服务端先校验路由段数，再解码一次并鉴权。中文、斜杠、百分号、问号和井号不再破坏领取请求，也不把额外路径段误识别为合法路由。

验证：真实回环 HTTP 闭环扩展为 4 种名称 × 成功/失败执行器，专项 8 passed，全量 135 passed；compileall、git diff --check 通过。执行器为假的，临时服务及数据库均按测试生命周期关闭。

证据边界：未访问微信、模型或真实远程节点；未验证代理层对编码斜杠的处理。URL 层会编码空格，但 /bind 当前仍限制单个无空白节点名，尚未覆盖带空格名称的聊天命令。无外部接口异常或重试。本轮不代表完整多机上线验收。
