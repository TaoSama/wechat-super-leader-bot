# 微信消息去重边界

ILink transport 持久化最近 1000 个已成功消费的账号、聊天、client_id 组合键。生成器继续执行时逐条原子保存成功记录，批次游标仍等到全部消费才推进。登录清空窗口。旧版无聊天范围的裸 ID 不导入新窗口，避免误吞其他聊天消息；升级时旧消息可能再次处理。

验证：全量 `.venv/bin/python -m pytest -q` 实测 70 passed；新增跨聊天相同 ID、相同时间戳、部分批次成功后重启、原子替换失败保留原文件测试。compileall 与 git diff --check 通过。

证据边界：去重依赖稳定的 client_id，时间戳不能视为唯一 ID。窗口仅保留 1000 条，超出后旧消息可能重放。原子替换测试为本机故障注入，未测试断电持久性或多进程写同一状态文件。副作用完成到成功记录落盘之间仍有崩溃窗口；没有 outbox 或发送端幂等确认，不能宣称回复恰好一次。未连接真实微信账号，无外部接口错误；失败测试均为模拟。
