# 节点任务回传确认

dispatch_once 现在要求控制面返回 updated=true 才返回已确认结果，并在返回列表中明确 completed/failed。
拒绝或缺失确认时抛错，不自动重新执行任务。领取响应在任何执行开始前校验整个批次：缺 ID、空 payload、重复 ID、非列表等均拒绝，不再生成随机 ID 或静默忽略异常条目。

验证：`.venv/bin/python -m pytest -q` 实测 87 passed；compileall、git diff --check 通过。新增 12 个离线用例覆盖正确确认、错误确认、畸形批次与执行异常回传。

证据边界：HTTP 响应和执行器均被模拟，未执行模型或发送外部消息。一次 dispatch_once 内不会自动重跑，不代表进程重启后的去重保证。结果持久化补报仍未实现，回传断线后需人工核对，不能宣称任务可靠交付已完成。无外部接口异常；本轮失败均为测试注入。
