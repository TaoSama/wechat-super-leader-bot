# 心跳错误证据与线程退出

## 修复

- 临时异常不再静默吞掉：记录异常类型、连续失败次数、恢复事件，不记录可能包含凭据的异常正文。
- ok=false 视为拒绝；首次心跳被拒绝时，不进入任务领取循环。
- 停止线程最多等待 16 秒（请求超时 15 秒加 1 秒余量）。超时明确抛错并保留线程引用，禁止假装停止或再启动重叠线程。
- 拒绝无限大、NaN、非正间隔；run 的心跳间隔不超过 30 秒。

## 验证与证据边界

`.venv/bin/python -m pytest -q`：实测 57 passed；compileall 与 git diff --check 通过。
新增测试覆盖停止超时保留引用、重启不重叠、拒绝响应、非法间隔；原异常恢复测试增加日志断言。
测试以本地线程事件控制时序，1～2 秒等待仅为测试上限，不是生产延迟观测。
没有网络、微信或模型执行数据；测试不能证明操作系统网络调用必定在 15 秒内退出。因此停止超时保留引用，而非保证线程已退出。
本轮无外部接口错误；此前错误恢复用例均为模拟注入。任务租约、持久化结果补报等仍有独立缺口。
