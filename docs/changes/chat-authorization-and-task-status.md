# 聊天授权与实际执行状态

空 ALLOWED_CHAT_IDS 现在拒绝所有外部聊天，包括名为 local 的发送者。仅进程内 handle 调用省略身份时保留本地演示入口。上线前必须通过环境变量或构造参数明确授权聊天 ID；不会根据首次来信自动授权。

普通文本当前没有调度实现：返回“已保存到记忆，尚未执行”，accepted=false、recorded=true，不再声称正在分析或派发。去掉重复记忆写入，未知斜杠命令明确拒绝。

验证：`.venv/bin/python -m pytest -q` 实测 121 passed；compileall、git diff --check 通过。新增 3 个用例，验证外部未授权调用无副作用、本地名称不能绕过和实际执行状态；既有 HTTP 测试显式配置授权聊天。

证据边界：离线命令测试及既有回环 HTTP 测试，不发送微信消息。授权聊天仍拥有全局会话/节点能力，未做按聊天任务所有权隔离。自然语言自动调度仍未实现；扫码不是唯一剩余工作。
