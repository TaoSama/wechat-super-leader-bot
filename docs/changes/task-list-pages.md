# 任务列表按需翻页

`/tasks [页码]` 默认第一页，每页 5 项、结果摘要最多 300 字符；显示页数和下一页命令，完整结果仍用 `/task <ID>`。响应 data 仅包含本页摘要，不暴露整个未分页结果。非法/越界页码有明确提示。列表查询增加 task_id 降序作为相同创建时间的确定性次排序。

按开发技能最小改动原则复用 list_tasks，数据库结构不变。注意目前仍读取所有行后分页，不是数据库级分页优化。
