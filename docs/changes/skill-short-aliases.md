# 唯一技能目录短名

嵌套技能保留规范相对路径，同时为唯一目录叶名提供别名。例如只有一个 `bundle/skills/review/SKILL.md` 时，`review` 与 `bundle/skills/review` 都可解析。发现第二个不同文件的同名目录时，短名失效，必须指定完整路径。每次发现实时计算，不缓存旧别名。

已存在的规范路径不被短名覆盖，内置技能名不被嵌套别名覆盖；多个重叠根指向同一物理文件不视为冲突。根优先级和路径越界检查沿用现有逻辑。白名单按请求名称精确检查：允许完整路径不自动授权短名，反之亦然。目录短名不是 SKILL.md frontmatter 的 name 字段，后者仍未解析。

按 go 技能最小改动原则，直接复用目录发现结果，不读取技能正文、不引入 YAML 解析器或新依赖。

## 验证

新增 6 个用例覆盖唯一别名、动态重名、规范名/内置名优先、两个方向的白名单和重叠根。

实测 `.venv/bin/python -m pytest -q`：230 passed in 2.17s；`.venv/bin/python -m compileall -q src`、`git diff --check` 通过。

## 证据边界

测试使用临时技能目录，并验证提示构建结果；没有调用模型、读取真实技能内容或发送外部消息。未做扫描性能测试，无延迟或吞吐推算；本轮无接口异常。发现/解析/提示构建三条本地路径均覆盖，真实模型是否遵循技能未验证。

短名不是稳定身份：新增同名技能会使简写失效，因此固定自动化与严格白名单建议继续使用完整相对路径。现有文件扫描和读取之间的竞态、symlink 目录遍历差异没有解决。

回退只移除 `_catalog` 的候选别名生成段及本轮测试，不改变任何实际技能文件或配置。
