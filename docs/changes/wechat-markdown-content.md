# 微信 Markdown 内容保全

本轮停止全局删除下划线、星号、波浪号和反引号：行内代码、围栏代码、链接目标独立处理，普通段落只去掉成对强调标记。标题和列表转换不再改写代码内的注释、负数或缩进内容。

验证：`.venv/bin/python -m pytest -q` 实测 75 passed；compileall、git diff --check 通过。新增 5 个参数化/独立测试，覆盖标识符、shell 路径/通配符、代码、链接目标、空行与强调。

证据边界：这是保守的轻量转换器，不是完整 CommonMark 解析器；嵌套复杂链接、未闭合围栏等仍不完全支持。4000 字符上限及截断仍存在，尚未实现分页发送。未发送微信消息，未测微信客户端渲染，无外部接口失败或重试。
