# 显式选择独立会话模型

新增机器人命令 `/fork --model gemini-3.7-flash-high "检查项目"`，支持 `-m` 和 `--model=名称`，无需模型前缀猜测。原 GPT/Claude 位置模型用法与普通任务用法保留。`/fork -h`、`--help` 和无参数返回用法，不退出 daemon。

显式参数使用 argparse（禁用缩写）和 shlex，不执行 shell。模型选项在任务前；任务从第一个位置参数开始。显式语法的引号用于分组，未引用空白会规范化为单空格；需要保留换行/内部空格时用引号包住整个任务，任务内字面引号需按 shell 分词规则转义。以连字符开头的参数会按新选项语法处理，旧此类正文应改为显式模型加引用任务。普通不以连字符开头的任务保留原正文。
