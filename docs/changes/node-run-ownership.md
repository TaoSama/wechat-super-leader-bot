# 节点实例主循环所有权

为 NodeAgent.run 添加非阻塞实例锁，覆盖注册、初始心跳、运行与清理的完整生命周期。同一实例第二次并发 run 立即拒绝，不注册、不领取任务，也不停止首个运行者的心跳。完成或异常退出后释放锁，允许后续调用。

若上次清理超时后心跳线程仍活着，新的 run 在任何网络调用前拒绝启动，避免复用已设置停止标记但尚未退出的旧线程。内部循环抽为 _run_loop，保持原有错误传播和 finally 清理。

## 验证

新增 3 个用例：真实线程间并发启动冲突且原心跳不受影响、初始失败后所有权释放、残留心跳拒绝重启且不调用注册。使用 Event 同步而非时间猜测，所有本轮线程正常释放并 join。

实测 `.venv/bin/python -m pytest -q`：259 passed in 2.22s；`.venv/bin/python -m compileall -q src`、`git diff --check` 通过。

## 证据边界

网络方法为测试替身，线程及 run 生命周期真实执行；没有跨机调用、微信发送或真实模型执行。测试检查并发拒绝、调用次数和线程状态相互一致，未做压力/时延测量，无性能推算或外部接口异常。

这是进程内单实例保护，不是跨进程或跨实例节点锁；手动并发调用 dispatch_once、register 或内部心跳方法仍不受 run 锁约束。跨进程任务领取继续依赖服务端事务与主键。结果持久化补报与安全重新注册仍未完成。

按开发技能限定为最小生命周期改动。回退只移除实例锁和 run 包装，将内部循环恢复到 run，保留原心跳实现与其它累计修改。
