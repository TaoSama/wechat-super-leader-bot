# 技能目录发现与加载边界

## 新增完成项

- 递归发现嵌套 SKILL.md，名称采用相对根目录路径，如 bundle-a/skills/review；单层名称保持兼容。
- resolve 仅接受发现目录中的精确名称，不把用户输入拼接到路径上。拒绝 ../、绝对路径及解析到根目录外的符号链接。
- 根目录本身允许指向实际技能根的符号链接；根内重名路径遵循配置顺序，嵌套同名叶子不产生歧义。
- 内置技能同样受 allowlist 约束，不能通过 build_prompt 绕过。
- 不再静默截断第 12000 字符后的指令；提示词携带技能源路径与相对资源基准目录。

## 验证与证据边界

`.venv/bin/python -m pytest -q` 实测 62 passed；compileall 和 git diff --check 通过。
新增 5 个离线用例覆盖嵌套重名、路径越界、内置白名单、长指令保全和根目录优先级。
仅在临时测试目录验证，不执行技能或访问外部接口，没有推算性能数字。
根目录中的文件视为可信输入；文件发现与读取之间的恶意并发替换尚无文件描述符级防护。
这里不解析 frontmatter name/别名，也不自动读取技能引用的资源；提示中给出基准目录，不等于资源已执行验证。
目录依赖 rglob 的符号链接遍历语义，根内符号链接目录可能不被递归展开。
