# 单独查询已保存的长期记忆

新增 `/memories [关键词]`，仅查询当前聊天通过 `/remember` 保存的 kind=memory 记录，按写入 ID 倒序返回最近最多 10 条。省略关键词时列出最近保存项；`/recall` 继续检索包含普通聊天的全部记忆类型，不改变原语义。

按开发技能最小改动原则，复用 MemoryStore.search，增加可选关键字参数 kind；过滤在 SQL LIMIT 前完成，避免最近聊天记录挤掉笔记。kind 与关键词均参数化，关键词仍按字面匹配 LIKE 元字符。沿用聊天隔离和入口授权；不更改数据库结构或已有内容。
